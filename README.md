# Ejercicios de programación

Actividades de clase del primer curso de DAW: fundamentos de Java organizados por temas (proyecto Maven en `IsmaelZeneddine/`).

## Contenido

| Tema | Qué trabaja |
| --- | --- |
| `TEMA1` | Hola mundo, operadores y excepciones |
| `TEMA2` | Bucles, cadenas y baterías de ejercicios |
| `TEMA3` | Vectores y matrices |
| `TEMA4` | Clases, objetos y recursividad |

## Requisitos y ejecución

- JDK 25 y Maven (o IntelliJ IDEA).
- `mvn compile`

Material de aprendizaje; algunas clases son pre-exámenes o ejercicios de clase.
